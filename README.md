## Currently Building — AI Company

**AI が事業を考え、プロダクトを作り、運営しながら自らも改善していく会社**を目指して、個人で開発しています。

現在の中心は、その活動を支える開発実行基盤です。計画・実装・レビューの役割分担、テスト・CI との接続、中断後の再開、権限の管理に取り組んでいます。

- **目指すこと** — 人間が方向性と権限の範囲を定め、AI が継続して価値を生み出すこと。
- **開発していること** — タスクの選定から実装・検証・修正までをつなぐ仕組み。
- **これからの課題** — 開発の自動化を、ユーザーへの価値や公開後の改善につなげること。

事業探索・集客・収益化までを含む全体の自律運営は、今後の目標です。
